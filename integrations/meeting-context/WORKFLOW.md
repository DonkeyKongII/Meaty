A self-introduction can propose a mapping; it must not overwrite a conflicting voice match. Speaker clustering remains experimental after the 111-cluster failure. Do not force invitee count, arbitrarily map names to group order, enroll mixed/short/overlapping speech, replace an existing voice reference automatically, or claim identity is confirmed without checking evidence. New people can be suggested; permanent voice enrollment remains a review step in the Speakers panel. Audio and voice embeddings stay local; transcript snippets and calendar context are processed by Codex as requested.
7. Save `{"action":"save","meeting_id":"...","status":"complete" or "needs_review","data":{...}}`. Include participants, calendar_title, calendar_source, notes and any identity_suggestions/company_sources. Read current context before edits, preserve manually confirmed attendees and existing notes/metadata, and verify the saved result via action=get and list. The helper computes company grouping and searchable participant/company text. It does not edit transcript/audio. Unresolvable event matches should be saved needs_review with a concise reason, so they do not retry forever. Transient browser failures stay pending; record bounded retries in a local checkpoint, and notify only after persistent failure requiring Ian's action.
8. Stay quiet when unchanged or no jobs exist. After actual enrichment, notify only for meaningful completion or a review/action needed, naming the meeting and uncertainty. Avoid routine heartbeat status messages.

The scheduler polls the local queue; this is not an immediate app-to-chat callback. It requires this Mac, Codex and signed-in Chrome to be available. No separate OpenAI API key or SDK service is configured.
